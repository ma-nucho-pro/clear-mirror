# Clear Mirror for Gemini CLI

Install the extension from the repository root:

```bash
gemini extensions install ./platforms/gemini-cli/clear-mirror --consent
```

Verify with `/extensions list` and `/skills list` after reloading or restarting Gemini CLI. The bundled skill is the same canonical workflow; extension subagents and hooks are not claimed unless the installed Gemini CLI version exposes and enables them.
